# 星辰早晨 - 家庭成长激励系统

一个基于 React + TypeScript + Node.js 的家庭任务管理和奖励系统，帮助家长通过游戏化的方式激励孩子完成任务。

## ✨ 功能特性

### 孩子端
- 📋 **任务管理**：查看任务、完成任务、提交审核
- 🎁 **心愿系统**：兑换商店、储蓄目标、幸运抽奖
- 🎒 **我的背包**：查看已兑换物品、撤销兑换
- 👑 **特权系统**：使用特权点兑换服务性奖励
- 🏆 **成就系统**：解锁各种成就徽章

### 家长端
- ✅ **任务审核**：多维度评分（时间、质量、主动性）
- 📊 **数据统计**：本周任务完成率、准时率、金币统计
- 🎯 **任务管理**：创建任务、使用预设模板快速添加
- 🎁 **心愿管理**：管理商店商品、储蓄目标、抽奖奖品
- 👑 **特权管理**：设置特权模板、管理特权列表
- 🏆 **成就管理**：自定义成就规则
- 👨‍👩‍👧 **家庭管理**：添加孩子、设置PIN码

## 🛠️ 技术栈

- **前端**：React 18 + TypeScript + Vite + Tailwind CSS
- **后端**：Node.js + Express + TypeScript
- **数据库**：SQLite
- **认证**：JWT Token

## 📦 安装与运行

### 前置要求
- Node.js >= 16
- npm 或 yarn

### 快速启动

1. **克隆项目**
```bash
git clone <your-repo-url>
cd star-coin
```

2. **安装依赖**
```bash
# 后端
cd backend
npm install

# 前端
cd ../frontend
npm install
```

3. **启动服务**

**Windows 用户 - 智能启动（推荐）**：
双击 `scripts/start_app.bat`，然后选择环境：
- **选项 1**：本地开发环境（端口 3000/3001）
- **选项 2**：生产服务器环境（端口 80）

**直接启动（跳过选择）**：
- 本地开发：双击 `scripts/start_app_local.bat`
- 生产服务器：双击 `scripts/start_app_production.bat`

**手动启动**：
```bash
# 终端1 - 启动后端 (端口 3001)
cd backend
npm run dev

# 终端2 - 启动前端 (端口 3000)
cd frontend
npm run dev
```

4. **访问应用**

**本地开发环境**：
- 前端：http://localhost:3000
- 后端API：http://localhost:3001
- 手机访问：http://你的IP:3000（需在同一WiFi）

**生产服务器环境**：
- 访问：http://starcoin.h5-online.com/ 或 http://localhost/
- 需要管理员权限（使用80端口）

## 🚀 生产服务器部署 / 升级（覆盖新代码后照这个做）

生产环境用 **Nginx 托管前端**、**Node 跑后端**。每次把新代码覆盖到服务器后，按顺序做：

1. 把新代码覆盖到服务器项目目录（保持 `backend/`、`frontend/` 目录结构一致地覆盖对应文件）。
   - ⚠️ **升级前务必先把服务器旧的 `frontend\dist` 整个删掉再重建**——直接覆盖合并会残留旧的 JS 分块，换版本后 index.html 引用的新分块和残留旧分块对不上，导致**部分页面白屏（页面 JS 404）**。
2. 双击 `scripts\setup_server_production.bat`
   —— 它会**自动**：装依赖 → 构建后端 → **构建前端(生成新的 `frontend/dist`)** → 校验数据库。全程回车用默认值即可（会继承上次的 JWT / 高德 Key 等配置）。
3. 双击 `scripts\start_backend_only.bat` 启动后端（Nginx 已负责前端 80 端口）。
4. **清一次浏览器 / 微信缓存**再打开页面：微信 → 我 → 设置 → 通用 → 存储空间 → 清理缓存。
   （前端 dist 换了，但 `index.html` 可能被缓存住，导致仍加载旧页面。）

> 重要：**只改了前端也必须跑 `setup_server_production.bat`**——只有它会重新 build 出新的 `frontend/dist`；只重启后端不会更新前端。

## 📌 最近更新

### 探索·发现资讯流 v2（多城市 / 年龄 / 有效期 + 官方源）
- **结构化推送**：家长推送活动可填场馆 / 区 / 分类 / 年龄段 / 活动起止 / 报名截止 / 价格 / 预约方式 / 官方链接 / 推荐理由 / 有效期；孩子端按**有效期（按天过期）、孩子年龄（生日推算）、所在城市**只显示合适的卡片。
- **官方源自动 + 其余手动**：家长「关注的网站」现支持 **RSS/Atom 订阅**（公众号可用 RSSHub 转成 RSS 后填入），系统定期抓取、家长审核后推给孩子；新增"常见官方源"一键填入。
- **抽奖"谢谢参与"**：不再放进背包，弹个提示就结束。

### 探索地图改进
- **孩子端地图搜索框**：按名称搜全家的探索地点（含还没定位的），选中即定位并弹详情。
- **按分类的地点清单**：地图上「📋 清单」按钮，按 博物馆 / 科技馆 / 公园 / 旅行… 分组浏览，点一条即定位到地图并可打卡。
- **自动补坐标（根治"加了地点看不到"）**：家长添加 / 编辑地点没给坐标时，用高德地理编码自动补上坐标（复用 POI 搜索那把 Web Key）；家长端「探索 → 设置」新增「🧭 给未定位地点补坐标」批量补历史地点。补上坐标后，这些地点才会出现在孩子地图的标记上。

### 配置 / 展示增强（P1b–P5）
- 家长探索统计支持按孩子查看 +「去过的地方」按类型清单。
- 宝箱稀有度统一为 5 档 + 启用上限 9；抽奖模板按稀有度分组、移除电影、屏幕类 ≤10 分钟；宝箱奖品可编辑。
- 探索成就扩充（含"科技馆""全能探索家"等）+ 家长手动颁发"高光时刻"入口。
