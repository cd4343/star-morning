# Phase 11 只读脱敏运营报告

## 使用方法

服务器部署最新累计包后，双击：

`scripts\generate_operations_report.bat`

默认统计最近滚动 7 天。命令行可指定 1–30 天，例如：

`scripts\generate_operations_report.bat 14`

生成文件固定为：

`logs\operations-report-latest.json`

把这一个 JSON 文件发给 Codex 即可，不要发送 `stellar.db`、日志原文或环境配置文件。

## 安全边界

- 数据库使用 SQLite `OPEN_READONLY` 和 `PRAGMA query_only` 双重只读保护。
- 不新增公网接口，也不要求开放服务器端口。
- 报告只包含全站汇总数，不含家庭或孩子 ID、姓名、电话、邮箱、任务/愿望内容、备注、地点、坐标、令牌或密钥。
- 日志只统计错误关键词行数，不复制任何日志文本。
- 报告会检查数据库完整性、外键异常、重复提交键、重复宝箱发放键、重复结算、一个孩子多个进行中愿望，以及不完整探索卡片误展示。

## 已知边界

系统目前不会持久化“重复点击被拦截了几次”，所以报告只能证明没有重复记录真正写入数据库，不能统计拦截次数。进程运行时长也没有可靠持久化来源，因此本版不伪造该指标。
