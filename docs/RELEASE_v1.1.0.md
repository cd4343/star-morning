# Release v1.1.0

发布日期：2026-05-14

## 本次目标

把孩子端第一入口从“任务列表”升级为“今日星图”，让孩子一进入系统就知道今天有哪些节点、下一步做什么、完成后会获得什么。

## 已完成

- 新增孩子端 `/child/map` 星图首页。
- 聚合展示今日任务、学习关卡、早晨流程、冷静充能、游戏票余额和心愿入口。
- 孩子登录后默认进入星图首页。
- 底部导航新增“星图”，原模块入口保留。
- 首页新增“现在只做下一步”推荐，降低启动困难和选择负担。
- 星图展示今日亮度、任务完成数、可得金币、游戏票余额和路线节点点亮状态。

## 上线影响

- 主要是前端页面和路由变化，不改变后端业务规则。
- 不需要替换服务器数据库。
- 孩子端默认入口由 `/child/tasks` 改为 `/child/map`。
- 原任务页、学习页、冷静页、早晨页、心愿页仍可从底部导航进入。

## 回归重点

- 孩子登录后是否进入星图首页。
- 星图节点点击后是否能进入对应页面。
- 任务、学习、早晨、冷静、心愿各模块原流程是否仍可用。
- 底部 7 个导航项在手机宽度下是否不拥挤、不遮挡。
- 星图在没有任务、没有学习关卡、接口部分失败时是否仍能显示可用内容。
