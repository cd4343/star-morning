# Phase 12 家长探索规划器部署与验收

Phase 12 将家长端探索默认入口改为“20 秒探索规划”，新增可信信源、字段证据、时效门禁、健康检查和覆盖率汇总。原有计划、记录、打卡、媒体、统计、家庭关注源和手动补充能力仍保留；旧工具收进高级设置。

## 部署前

1. 只上传最新累计增量包中的 `backend`、`frontend`、`scripts` 和 `docs`，合并覆盖服务器项目根目录。
2. 不删除服务器原目录，不上传增量包外层目录。
3. 严禁替换 `stellar.db`、`stellar.db-wal`、`stellar.db-shm`、`uploads`、`backups`、日志和 `scripts\production_env.local.bat`。

## 安全部署

以管理员身份运行：

```bat
scripts\deploy_server_production.bat
```

脚本会先隔离构建和验证，再备份当前运行产物及数据库，随后发布构建、执行幂等迁移并检查健康状态。正常重启仍使用：

```bat
scripts\start_backend_only.bat
```

首次配置服务器时才使用 `scripts\setup_server_production.bat`，本次增量更新无需重复初始化。

## 验收

- 家长端探索默认进入“发现”，可用快捷条件、自然语言或官方链接查找。
- 结果最多为一项首选和两项备选；可靠结果只有一至两项时不补假数据。
- 每张卡有真实名称、有效图片、地点信息、说明、核验日期和可信标签。
- “人少”“精确车程”等当前不能可靠核验的说法会明确提示，不显示为已满足。
- “加入家庭计划”和“给孩子看看”互不替代，重复点击不会重复创建计划。
- 无可信结果或信源失败时显示明确空态或错误，不生成兜底假卡片。
- 计划、记录、打卡、媒体、统计、孩子意向和孩子端探索仍可正常使用。
- 服务器可运行 `scripts\generate_operations_report.bat` 查看脱敏后的信源健康和发现覆盖率。

## 回滚

若发布验证失败，部署脚本会恢复本次发布前的前后端运行产物。需要人工回滚时，恢复 `backups\releases\<本次时间戳>\` 中的构建并重新运行 `scripts\start_backend_only.bat`。

不要为了回滚 Phase 12 删除新表或新列，也不要覆盖真实数据库；迁移全部为只增不删，旧代码会忽略新增结构。
