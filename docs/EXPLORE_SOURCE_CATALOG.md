# 探索可信信源目录

更新时间：2026-07-17

本目录区分“已自动接入”和“待适配”。只有完成解析、近期性、字段完整度和回归测试的来源，才会进入孩子可见的推荐结果。列入目录不等于允许自动展示。

## 可信等级

- **S**：场馆或活动主办方官方页面，可确认活动时间、场馆、年龄等临时信息。
- **A**：国家/地方政府、公共服务平台或地图服务，可确认其职责范围内的事实。
- **B**：可靠聚合或发现平台，只能提供线索；关键日期、费用、预约方式需要官方来源确认。
- **家庭**：家长提交的链接或内容，仅在本家庭内使用，仍需通过安全和完整度检查。

## 运行规则

1. 活动证据默认 6 小时有效；地点稳定信息默认 30 天有效。
2. 单个来源失败时保留其他已核验结果并标记为部分结果，不显示来源错误细节给家长。
3. 标题、真实图片、说明、场馆/地址和日期任一关键字段缺失，内容只留在后台候选或直接拒绝。
4. 不根据省名猜城市，不根据标题猜价格、年龄、开放时间或预约方式。
5. 每周覆盖报告只记录来源健康、城市覆盖和结果数量，不保存家长的原始搜索文字。
