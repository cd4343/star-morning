# Phase 14：星希望欢迎页与短信内测部署

## 本次累计内容

- 用户可见品牌统一为“星希望”。
- 手机首次访问先显示欢迎页，登录和注册按钮立即可用；同一浏览器后续不重复拦截。
- 注册、短信登录和密码找回接入阿里云号码认证服务（PNVS）。
- 仅支持中国大陆 11 位手机号；验证码只有阿里云校验返回 `PASS` 才能通过。
- 同一手机号 60 秒内不可重发，每小时最多 5 次、滚动 24 小时最多 10 次。
- 修复短信记录与创建家庭在多人并发时的 SQLite 事务交错问题。

## 服务器更新

1. 只上传 `临时\LATEST_PATCH_PATH.txt` 指向的最新累计包。
2. 将包内 `backend`、`frontend`、`scripts`、`docs` 合并覆盖到服务器项目根目录。
3. 不删除服务器原目录，不替换 `stellar.db`、WAL/SHM、`uploads`、`backups`、`logs`、
   `.tmp`、`node_modules` 或 `scripts\production_env.local.bat`。
4. 首次启用短信时运行 `scripts\setup_server_production.bat`：
   - `SMS provider` 直接回车，默认选择 `aliyun-pnvs`；
   - 输入 AccessKey ID 和 AccessKey Secret；
   - 签名直接回车使用 `恒创联众`；
   - 模板直接回车使用 `100001`。
5. 后续发布运行 `scripts\deploy_server_production.bat`。
6. 服务器日常重启仍运行 `scripts\start_backend_only.bat`。

生产密钥只写入服务器上被 Git 忽略的 `scripts\production_env.local.bat`。不要截图、打包或
提交该文件。

## 上线验收

部署后至少使用 1—2 个真实手机号检查：

1. 首次访问域名能看到“星希望”欢迎页，点击后立即进入注册或登录。
2. 注册页获取验证码成功，验证码可完成注册并创建家庭。
3. 已注册手机号可使用验证码登录。
4. 错误验证码、重复使用验证码、60 秒内重复发送都会被拒绝。
5. 家长端和孩子端原有任务、审核、奖励、探索、商店与抽奖页面可正常打开。
