# Phase 11 家庭试运行手册

Phase 11 不新增孩子端玩法，先确认现有闭环连续稳定。自动验收只使用 `.tmp/` 临时数据库：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\verify_phase11_acceptance.ps1
```

## 部署后连续 7 天观察

每天只记录是否成功、错误时间和必要截图，不记录孩子位置、聊天内容或额外行为轨迹。

- 家长新建或调整任务后，孩子端当天完整显示。
- 孩子单击开始、提交，惊喜宝箱立即出现且只发一次。
- 家长审核后，金币和学习省时游戏时间只结算一次。
- 孩子愿望始终最多一个进行中；家长可处理。
- 不完整探索内容只在家长端，完整内容才进入孩子端推荐。
- 家长端审批、报告、工具三个区域均可进入，无白屏或空白卡死。

## 通过标准

- 连续 7 天无白屏、数据丢失、重复发奖或跨家庭数据访问。
- 每次部署前后 `verify_phase11_acceptance.ps1` 全部通过且没有跳过。
- 若发现问题，记录时间、账号角色、操作路径和截图；先回滚本次代码包，不替换 `stellar.db`。

## 不在本阶段处理

电子宠物、新货币、新导航和全面重构均延后。只有试运行证明现有流程稳定后，才进入 Phase 12 安全与移动端发布准备。
