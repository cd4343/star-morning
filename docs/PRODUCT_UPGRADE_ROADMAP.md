# Star Coin 产品设计升级规划

最后更新：2026-05-14

## 1. 产品定位升级

Star Coin 当前已经具备“家庭任务激励系统”的基础能力。下一阶段建议升级为：

> 家庭执行功能支持系统：帮助孩子把起床、学习、运动、情绪调节和生活选择，变成可启动、可完成、可反馈、可复盘的成长流程。

核心目标不是让孩子被更多规则管理，而是让孩子逐渐形成：

- 我知道下一步做什么。
- 我可以先做很小的一步。
- 我做完马上能看见反馈。
- 我可以通过努力获得选择权。
- 我情绪上来时有办法降下来。
- 我不是“坏”或“懒”，我是正在练习启动、坚持和自我调节。

## 2. 当前产品基础

### 孩子端已有能力

- 今日/本周任务。
- 倒计时、暂停、继续、提交。
- 并行任务悬浮窗。
- 宝箱奖励和宝箱说明。
- 商城、储蓄、抽奖、背包、特权兑换。
- 成就、等级、惩罚记录、宝箱记录。

### 家长端已有能力

- 任务管理、并行任务、家庭任务。
- 待审核、历史审核、评分与惩罚。
- 心愿商品、储蓄目标、抽奖奖池、宝箱设置。
- 特权管理、成就管理、家庭成员管理。
- 惩罚设置和惩罚统计。
- 初版规则助手：任务奖励、商品金币、特权点建议。

### 已有规则系统

- 金币：短期消费和商品兑换。
- 经验：成长进度。
- 特权点：稀缺选择权。
- 宝箱/抽奖：惊喜反馈。
- 成就：长期成长确认。
- 惩罚：问题行为记录和扣除；后续建议逐步加入“补救任务”。

## 3. 设计原则

### ADHD 友好原则

- 短反馈优先：尽量让孩子在 3-10 分钟内看到一个完成结果。
- 小步启动：大任务必须拆成孩子能开始的第一步。
- 降低选择过载：孩子端每次只突出 1 个主行动。
- 高确定性、低随机性：宝箱和抽奖要有说明、保底和可预期路径。
- 情绪先行：孩子急躁时先降强度，不讲大道理。
- 少惩罚、多修复：问题行为优先用补救流程、复盘和环境调整。

### UI 原则

- 孩子端：卡通、地图、能量、关卡、图标化、少文字、强反馈。
- 家长端：清晰、专业、配置效率高，避免过多装饰。
- 移动端：所有弹窗、悬浮窗、底部抽屉必须限制在手机框可见区域。
- 规则可见：奖励、消耗、概率、保底、到账状态都要解释清楚。

## 4. 目标体验闭环

### 学习闭环

```text
学校作业/学习目标
→ 家长拆成学习关卡
→ 孩子选择今日关卡
→ 情绪/难度检查
→ 3-10 分钟小步执行
→ 即时星光/经验/宝箱碎片
→ 最终提交审核
→ 家长反馈质量与建议
→ 成就/礼包/长期成长
```

### 情绪闭环

```text
孩子急躁/痒/生气/不想写/想玩手机
→ 点击“我现在很难受”
→ 选择感受和强度
→ 系统给 30-90 秒安抚流程
→ 替代动作：按压、冷敷、呼吸、离开屏幕、求助
→ 完成后获得冷静星/经验
→ 家长端记录触发源和有效方法
```

### 生活选择闭环

```text
完成任务获得金币/票券
→ 进入早餐/游戏票/特权选择
→ 基础需求免费，升级和选择权消耗积分
→ 孩子感到努力带来可控选择
```

## 5. 模块规划

### A. 学习星图 / 学习冒险

定位：把作业、背诵、阅读、复习、预习变成游戏化学习关卡。

孩子端：

- 学习地图：首页展示今日主线、支线、勇气关卡、轻松关卡、Boss 关卡。
- 关卡卡片：学科、类型、预计时长、奖励、当前进度。
- 启动前检查：我现在感觉如何，是否需要家长陪跑。
- 小步计时：3/5/10 分钟短段。
- 我卡住了：选择“不会做、太多了、太烦了、怕错、想休息”。
- 提示卡：先读题、只做第一题、找关键词、请家长陪 3 分钟。
- 证明方式：拍照、录音、文字、家长确认。

家长端：

- 学习任务模板：数学作业、背诵课文、英语口语、阅读、错题订正。
- 拆解方式：按题数、页数、时间、步骤。
- 孩子感受：喜欢、普通、无聊、害怕。
- 阻力等级：低、中、高。
- 奖励策略：启动奖励、每关奖励、最终奖励、连续奖励。
- 陪跑设置：是否需要家长前 3-5 分钟陪伴启动。

后台建议表：

- `learning_quests`：学习任务定义。
- `learning_steps`：关卡步骤。
- `learning_sessions`：孩子执行记录。
- `learning_proofs`：图片/录音/文字证明。
- `learning_stuck_events`：卡住原因记录。

### B. 情绪急救系统

定位：不是让孩子“不许急”，而是让孩子在急躁时有一套可执行的替代动作。

孩子端入口：我现在很难受。

场景：

- 我很痒。
- 我很生气。
- 我不想写作业。
- 我起不来。
- 我想玩手机。
- 我太累了。

每个场景包含：

- 强度选择：一点点、很难受、忍不住。
- 安抚倒计时：30/60/90 秒。
- 替代动作：冷敷、按压、握拳、深呼吸、喝水、离开屏幕、请家长陪伴。
- 完成反馈：冷静星、经验、连续冷静天数。

家长端：

- 触发记录：时间、场景、强度、使用方法、是否有效。
- 趋势分析：睡前痒、放学作业冲突、停止游戏冲突、早晨起床冲突。
- 健康提示：频繁瘙痒、影响睡眠、抓破时建议咨询医生。

后台建议表：

- `emotion_checkins`：情绪/身体不适记录。
- `calm_actions`：安抚动作模板。
- `calm_sessions`：实际安抚过程。

### C. 游戏票 / 屏幕时间票

定位：把手机游戏从冲突点变成可见、有限、可预期的选择权。

规则：

- 每天可有少量基础屏幕时间，由家长设置。
- 完成学习、运动、早晨流程可获得游戏票。
- 游戏票有每日上限，避免无限刷任务换游戏。
- 睡前、吃饭、作业前等时段可禁用。
- 游戏结束后进入“降速流程”：眼睛休息、喝水、拉伸、收好设备。

孩子端：

- 游戏票余额。
- 今日可用时段。
- 开始游戏倒计时。
- 结束前提醒。
- 结束后的降速小任务。

家长端：

- 游戏票规则。
- 每日上限。
- 禁用时段。
- 哪些任务可产出票。
- 超时处理：提醒、冻结、需要家长确认。

后台建议表：

- `screen_tickets`：游戏票余额和来源。
- `screen_sessions`：使用记录。
- `screen_rules`：家庭规则。

### D. 早餐小厨房 / 早晨流程

定位：用早餐选择权帮助孩子更愿意完成早晨流程。

重要边界：

- 基础早餐永远免费。
- 积分只用于选择权和升级，不用于剥夺基本饮食。

孩子端：

- 卡通早餐卡片。
- 今日可选早餐。
- 基础免费选项。
- 升级选项：水果、饮品、喜欢的主食、周末特别早餐。
- 花费金币或早餐券后生成“今日早餐订单”。

家长端：

- 早餐分类：主食、蛋白、水果、饮品、特别早餐。
- 价格：0 金币基础项，5-30 金币小升级，50+ 金币周末特别。
- 可用日期：工作日/周末。
- 健康规则：至少包含主食或蛋白。
- 早晨流程绑定：起床、洗漱、喝水、早餐选择。

后台建议表：

- `breakfast_items`：早餐项。
- `breakfast_menus`：每日菜单。
- `breakfast_orders`：孩子选择记录。
- `morning_routines`：早晨流程配置。

### E. 奖励规则助手 v2

定位：从“按时间给分”升级为“按任务类型和真实努力给分”。

建议公式：

```text
建议金币 = 分类基础分 * 难度系数 * 抗拒度系数 * 独立度系数 * 质量系数
建议经验 = 建议金币 * 分类经验系数
特权点 = 连续性/高自主/高挑战任务触发，不建议高频发放
```

分类差异：

| 分类 | 主要依据 | 金币 | 经验 | 特权点 |
| --- | --- | --- | --- | --- |
| 学习 | 启动、专注、尝试、改错、完成质量 | 中 | 高 | 连续或高挑战 |
| 运动 | 强度、目标完成、安全、坚持 | 中 | 高 | 连续运动 |
| 劳动 | 辛苦程度、主动性、完成质量 | 中 | 中 | 少量 |
| 生活习惯 | 是否按时、是否少提醒 | 低中 | 中 | 连续达成 |
| 情绪调节 | 使用了正确替代动作 | 低 | 高 | 连续冷静 |
| 早餐/选择 | 不直接产出高奖励，主要消耗金币或票券 | 低 | 低 | 不建议 |

家长端呈现：

- 推荐值。
- 推荐依据。
- 一键套用。
- 今日最多可获得预览。
- 与商品/特权价格的平衡提示。

### F. UI 美化与体验统一

孩子端视觉：

- 首页从列表升级为“今日地图”。
- 学习关卡使用地图节点、星星、能量条。
- 情绪急救使用大按钮和卡通引导。
- 早餐小厨房使用卡通食物卡片。
- 完成反馈使用音效、动效、成就礼包。

家长端视觉：

- 管理后台化：任务、学习、规则、奖励、情绪、早餐分区清晰。
- 每个配置页顶部有“规则说明”和“推荐配置”。
- 趋势视图：哪些任务抵触高、哪里常卡住、什么安抚方法有效。
- 审核页减少操作负担，支持批量处理和异常突出。

## 6. 版本路线

### v1.0.6 学习闯关 MVP

目标：优先解决学习抵触、作业启动困难。

范围：

- 家长端学习关卡管理。
- 学习模板。
- 孩子端学习星图。
- 关卡步骤、短计时、我卡住了。
- 学习奖励助手 v1。
- 学习证明提交。

不做：

- 复杂 AI 自动拆题。
- 学校系统对接。
- 复杂统计报表。

### v1.0.7 情绪急救 + 游戏票

目标：处理急躁、痒、停止游戏冲突、手机游戏依赖。

范围：

- 我现在很难受入口。
- 场景化安抚流程。
- 冷静星和情绪记录。
- 游戏票规则、余额、使用记录。
- 游戏结束降速流程。

不做：

- 医疗诊断。
- 自动判断皮肤疾病。
- 强制锁机系统级控制。

### v1.0.8 早餐小厨房 + 早晨流程

目标：改善起床困难，让积分进入真实生活选择。

范围：

- 早餐项管理。
- 今日菜单。
- 孩子早餐选择。
- 基础免费、升级消耗金币/早餐券。
- 早晨流程微任务。
- 能量训练小任务。

### v1.0.9 规则助手 v2 + 家长洞察

目标：让家长设置更有依据，降低随意性。

范围：

- 分类化奖励公式。
- 难度、抗拒度、独立度、质量系数。
- 今日收益预览。
- 商品/特权经济平衡提示。
- 学习和情绪趋势洞察。

### v1.1.0 UI 统一升级 + 回归测试

目标：统一视觉风格和关键流程稳定性。
当前进展：孩子端地图式首页 MVP 已在 v1.1.0 落地，剩余为视觉统一、家长后台重组和自动化回归。

范围：

- 孩子端地图式首页。
- 家长端配置后台重组。
- 弹窗、底部抽屉、卡片组件规范。
- 前后端主要流程回归脚本。
- 上线检查清单。

## 7. 数据与上线安全

- 每次功能上线继续保留版本号。
- 新增字段只做追加迁移，不覆盖线上数据库。
- 旧数据默认归入安全分类，例如“其他”“成长”“基础”。
- 历史奖励不自动补发，除非家长明确触发。
- 上线前必须跑前后端构建。
- 涉及金币、经验、特权点、背包的变更必须说明升级影响。

## 8. 后续开发优先级

1. 先做学习闯关，因为它直接对应当前最大痛点：学习抵触和作业启动。
2. 再做情绪急救，因为情绪失控会阻断所有规则。
3. 再做游戏票，因为手机游戏是高频冲突源，也是可转化的选择权。
4. 再做早餐和早晨流程，因为它能把积分系统接入真实生活，提高早晨配合度。
5. 最后做规则助手 v2 和 UI 统一升级，让系统更长期、稳定、可解释。
