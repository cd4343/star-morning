# Star Coin v1.0.9 发布说明

日期：2026-05-14

## 本次新增

- 新增家长端“规则/洞察”入口。
- 规则助手 v2 支持按任务类别给出推荐金币、经验、特权点。
- 支持分类：学习、运动、劳动、生活习惯、情绪调节、早餐选择、其他。
- 规则计算纳入预计分钟、难度、抗拒度、独立度和质量，不再只按时间粗略评估。
- 家长洞察聚合近 14 天数据：
  - 学习卡住点和高摩擦学习关卡。
  - 情绪触发场景和有效安抚动作。
  - 早晨流程完成情况。
  - 游戏票使用分钟数。
  - 任务金币收入、背包消费、早餐消费。

## 上线影响

- 需要更新前端和后端程序。
- 不需要覆盖服务器数据库。
- 本版本不新增数据库表，只读取已存在的学习、情绪、早餐、游戏票、任务和背包数据。
- 规则助手只提供推荐值，不会自动修改已有任务、商品、特权或成就配置。
- 洞察数据越多越有价值；新家庭或刚升级后的家庭可能会显示“暂无记录”。

## 建议回归

- 家长端：进入“规则/洞察”，切换“规则助手”和“成长洞察”两个页签。
- 规则助手：修改类别、分钟、难度、抗拒度、独立度、质量，确认推荐金币/经验/特权点随之变化。
- 洞察：确认无数据时不白屏，有数据时能展示学习、情绪、早晨、游戏票和金币流向。
- 权限：孩子账号不能访问家长端规则/洞察接口。
