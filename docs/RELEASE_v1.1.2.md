# Star Coin v1.1.2 发布说明

发布日期：2026-05-14

## 本次目标

本版本修正孩子端试用中暴露出的理解成本问题：星图按钮含义、奖励商店分类、早晨流程、游戏票说明、“我的”页定位，以及冷静记录可能刷经验的问题。

## 已完成

- 星图右上角由星光图标改成“刷新”按钮。
- 孩子端奖励商店增加分类筛选。
- 家长端商品分类扩展为零食、玩乐、屏幕、餐饮、学习、外出、特权、其他。
- 冷静记录后端增加防刷经验规则：每天最多 3 次可加经验，两次加经验至少间隔 10 分钟。
- “我的”页首屏增加成长档案、资源和成就预览，惩罚记录放到下方复盘。
- 挑战中心“早上”改成早晨流程/早餐聚合入口，不再把起床动作展示为多个独立点亮项。
- 奖励页和冷静页补充游戏票说明，明确游戏票在冷静页使用。

## 上线影响

- 不需要替换服务器数据库。
- 冷静记录仍然会保存，但超出每日上限或冷却时间内不会加经验。
- 旧商品没有分类时，前端会按标题做兜底分类；家长下次编辑保存后会写入明确分类。
- 屏幕时间商品不会自动删除，但建议后续逐步迁移到游戏票规则统一管理。

## 回归重点

- 孩子端星图刷新按钮含义是否清楚。
- 奖励页商店分类筛选是否能看到屏幕/餐饮等分类。
- 家长端新增/编辑商品时分类是否能保存。
- 冷静页连续点击“做到了/有帮助”是否不会重复加经验。
- 挑战中心“早上”是否能看到早餐入口和早上任务说明。
- “我的”页首屏是否先呈现成长档案而不是惩罚记录。
