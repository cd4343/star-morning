# Phase 13 上海与全国可信探索信源部署说明

## 本阶段内容

- 上海专属：自动接入上海博物馆活动、上海图书馆活动。
- 全国能力：保留高德全国地点检索，并接入国家公共文化云近期活动。
- 信源目录：新增文化和旅游部全国联播、国家文物局博物馆名录、重点国家级场馆、上海文旅和上海重点场馆等受控来源。
- 真实性门槛：过期、城市不明确、无图片、无说明、无场馆或明显不适合儿童的活动不会展示。
- 降级策略：单个来源失败时继续返回其他可靠结果；不会用虚构卡片填满三个位置。

## 服务器更新

只上传 `临时/LATEST_PATCH_PATH.txt` 指向的最新累计包。把包内 `backend`、`frontend`、`scripts`、`docs` 合并覆盖到服务器项目根目录，不要删除服务器现有目录。

严禁覆盖或删除：

- `stellar.db`、`stellar.db-wal`、`stellar.db-shm`
- `uploads`、`backups`、`logs`、`.tmp`
- `node_modules`
- `scripts/production_env.local.bat` 及其他密钥/环境文件

覆盖后以管理员身份运行：

```bat
scripts\deploy_server_production.bat
```

以后正常重启仍使用：

```bat
scripts\start_backend_only.bat
```

## 部署后验收

1. 家长端探索搜索“上海 + 博物馆/阅读/导览”，可看到符合日期与儿童门槛的官方活动；没有合格内容时显示真实空态。
2. 搜索其他城市时，高德地点仍正常；国家公共文化云只有在原文明确包含该城市且活动未结束时才出现。
3. 每张活动卡均有真实名称、缓存图片、说明、场馆、日期、来源和核验时间。
4. 任意一个外部来源暂时不可用，不应导致已有可靠地点和缓存结果消失。
5. `http://127.0.0.1/api/health` 返回 `status: ok`。

## 回滚

按增量包 `ROLLBACK.md` 恢复本阶段涉及的后端源文件后重新执行生产部署脚本。本阶段没有删除、重命名或重算业务数据，也不携带数据库文件。
