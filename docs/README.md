# 文档目录说明

本目录包含项目的各种文档。

## 文档列表

| 文档 | 说明 |
|------|------|
| `ARCHITECTURE.md` | 系统架构设计文档 |
| `FEATURES.md` | 功能需求与业务规则文档 |
| `REQUIREMENTS_BACKLOG.md` | 沟通中沉淀的需求、问题、状态和建议版本 |
| `PRODUCT_UPGRADE_ROADMAP.md` | 产品升级总规划：学习闯关、情绪急救、游戏票、早餐小厨房、规则助手 v2 |
| `PRODUCT_UX_ADHD_ANALYSIS.md` | ADHD 友好化产品逻辑和体验分析 |
| `RULES_AND_ECONOMY.md` | 倒计时、奖励、惩罚、宝箱、抽奖、商品、特权点规则 |
| `AUTH_MOBILE_LOGIN_PLAN.md` | 手机号、短信验证码、一键登录的设计规划与测试清单 |
| `DEPLOYMENT.md` | 部署指南 |
| `CHANGELOG.md` | 更新日志 |
| `CODE_HEALTH_REPORT.md` | 代码健康检查报告 |
| `HOSTS_SETUP.md` | Hosts 文件配置说明 |

## 阅读顺序建议

1. **新成员入门**：`ARCHITECTURE.md` → `FEATURES.md`
2. **产品规划**：`REQUIREMENTS_BACKLOG.md` → `PRODUCT_UPGRADE_ROADMAP.md` → `PRODUCT_UX_ADHD_ANALYSIS.md`
3. **规则设计**：`RULES_AND_ECONOMY.md`
4. **登录规划**：`AUTH_MOBILE_LOGIN_PLAN.md`
5. **部署应用**：`DEPLOYMENT.md` → `HOSTS_SETUP.md`
6. **代码维护**：`CODE_HEALTH_REPORT.md`
7. **版本更新**：`CHANGELOG.md`
