# Star Coin v1.0.7 发布说明

日期：2026-05-14

## 本次新增

- 新增“冷静”孩子端入口：情绪急救、30 秒冷静倒计时、替代动作选择、完成后记录经验。
- 新增“游戏票”孩子端功能：显示今日额度、额外票、已用时间、可用窗口，并支持开始/结束一次游戏时间。
- 新增“情绪/游戏票”家长端入口：配置每日基础分钟、每日上限、票面分钟、冷却分钟、工作日/周末可用时间。
- 家长端可发放或扣减孩子当天游戏票，并查看孩子今日余额和最近冷静记录。
- 新增后端 API 与数据库表，完整保存情绪记录、游戏票规则、游戏票流水和游戏票会话。

## 上线影响

- 需要更新前端和后端程序。
- 不需要覆盖服务器数据库。
- 后端启动时会新增四张表：`emotion_checkins`、`screen_time_rules`、`screen_time_ledger`、`screen_time_sessions`。
- 现有任务、金币、经验、家庭、心愿、成就、宝箱数据不会被替换。
- 游戏票规则默认开启：每日基础 10 分钟、每日上限 45 分钟、工作日 17:30-20:30、周末 09:00-20:30。

## 建议回归

- 家长端：进入“情绪/游戏票”、保存规则、给孩子发放/扣减游戏票、查看冷静记录。
- 孩子端：进入“冷静”、完成一次情绪急救、查看经验变化、在允许时间内开始并结束游戏票。
- 权限：孩子端不能访问家长端规则接口，家长端不能调用孩子端开始游戏票接口。
- 数据：确认服务器升级时只部署程序和构建产物，不用本地 SQLite 覆盖服务器数据库。
