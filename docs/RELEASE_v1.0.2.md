# v1.0.2 线上升级说明

发布日期：2026-05-13

## 修复内容

- 宝箱设置真正生效：关闭、必触发、简单/中等/困难概率、保底次数。
- 宝箱奖励发放后写入 `chest_records`，孩子端可查看宝箱历史。
- 兼容 `chest_settings` 新旧表结构，避免线上表结构差异导致设置插入或更新失败。
- 孩子端并行任务计时条改为可拖动浮动面板，减少遮挡。
- 大计时器根据用户点击位置附近打开，不再只按整体界面中心打开。

## 数据影响

- 不需要替换服务器数据库。
- 本地 `stellar.db`、`backend/stellar.db`、`backend/database.sqlite` 都不要上传覆盖服务器数据。
- 后端启动时会自动尝试添加 `chest_settings.updatedAt` 字段；如果字段已存在会跳过。
- 本版本不会删除或重建线上数据表。

## 建议上线步骤

1. 备份服务器上的 `stellar.db`、`stellar.db-wal`、`stellar.db-shm`。
2. 发布 `backend` 程序代码，执行 `npm install`（如依赖未变可跳过）和 `npm run build`。
3. 重启后端服务，确认 `/api/health` 返回 `ok`。
4. 发布 `frontend/dist`。
5. 用测试家庭或低风险任务验证：
   - 家长端关闭宝箱后，孩子提交任务不再触发宝箱。
   - 设置“必触发”后，孩子提交任务会触发宝箱。
   - 设置保底次数后，连续未触发达到次数时会触发。
   - 孩子端宝箱记录能看到新记录。
   - 并行任务计时面板可以拖动，点击任务附近打开大计时器。

## 回滚说明

- 可回滚前后端程序到 v1.0.1。
- 数据库新增的 `updatedAt` 字段不会影响 v1.0.1 正常读取。
- 如果必须完全回滚数据，请使用升级前备份的数据库文件。
