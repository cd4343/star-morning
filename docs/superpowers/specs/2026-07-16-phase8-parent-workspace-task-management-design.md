# Phase 8 家长工作台与任务管理设计

**状态：** 方案 A 已确认，等待书面规格复核后进入实施计划

**范围：** 家长首页四 Tab、账号级每日欢迎弹窗、审批与数据报告分区、全部工具分组、任务管理三 Tab、相关代码拆分和回归测试

**交付方式：** Phase 8A 与 Phase 8B 分批提交、分别验证，最终生成一份累计服务器包

## 1. 目标与成功标准

Phase 8 解决两个直接相连的问题：家长首页把审批、报告和工具堆在同一长页面；任务管理虽然功能完整，但家长无法直接确认孩子今天实际会看到什么。

成功标准：

1. 家长首页采用“总览 / 审批 / 数据报告 / 全部工具”四个顶部 Tab。
2. 孩子统计数据完整保留并集中到“数据报告”，可按孩子查看。
3. 审批的待处理、历史、批量处理、评分、打回、惩罚和调整能力全部保留。
4. 现有 11 个管理工具入口全部保留，只改变分组和入口层级。
5. “欢迎使用星辰”每天按家长账号和北京时间最多自动弹出一次，关闭后可从总览主动重看。
6. 任务管理采用“今日安排 / 全部任务 / 家庭合作”三个 Tab，并由后端复用孩子端同一任务日期规则生成今日预览。
7. 普通任务、模板、单次任务、每日任务、自定义星期、完成方式、奖励建议、审核重点、并行任务和家庭合作任务全部可继续创建、编辑和删除。
8. 375px 无水平溢出，触控目标不小于 44×44px；新增可见文字使用 i18n key。
9. 前后端构建、后端新增规则测试和前端完整 smoke test 全部通过，无测试静默跳过。

## 2. 范围拆分

### 2.1 Phase 8A：家长工作台

- 重组 `/parent/dashboard`，不新增一级底部导航。
- 新增四个页面内顶部 Tab。
- 拆分当前家长首页组件，保持现有 API 和审批结算规则。
- 增加账号级每日欢迎领取接口与可追加数据库字段。

### 2.2 Phase 8B：任务管理

- 重组 `/parent/tasks` 为三个 Tab。
- 增加家长端“今日安排”只读预览接口。
- 简化新建与编辑任务的首屏字段，高级字段折叠但不删除。
- 拆分任务表单、模板选择器、任务列表和家庭合作列表。

Phase 8A 验证通过后才开始 Phase 8B。两批可以独立回滚，不能把两个超大页面一次性替换后再排查问题。

## 3. Phase 8A 信息架构

### 3.1 顶部与 Tab

保留现有“家长模式”和“切换账号”能力。Header 下方增加四个等宽、至少 44px 高的 Tab：

1. **总览**：默认 Tab，只展示当天需要关注的信息和必要入口。
2. **审批**：显示待审批数量徽标，容纳待审批、历史和全部审核流程。
3. **数据报告**：容纳孩子统计、周报、金币、成就和体验质量数据。
4. **全部工具**：按用途分组展示现有管理入口。

Tab 使用 URL 查询参数 `?tab=overview|approvals|reports|tools` 保存当前页位置；未知参数回落到 `overview`。从收件箱、欢迎弹窗或总览点击“去审批”时切换为 `approvals`，不滚动查找长页面。

### 3.2 总览

总览只保留当天真正需要处理的摘要：

- 今日任务数、已完成数、待审批数。
- `ParentInbox` 中的关键事项。
- 当天处于低电量模式的孩子提示。
- 跨天自动完成提醒摘要。
- “孩子今天的安排”入口，进入任务管理的今日安排 Tab。
- 本周报告的一条简短趋势提示；完整数据只在数据报告展示。

新家庭没有任务时继续显示建立第一个任务的明确主按钮，不因欢迎引导改为弹窗而失去空状态入口。

### 3.3 审批

以下现有能力全部迁移到审批 Tab，不改变接口和结算公式：

- 待审批列表与审核历史切换。
- 日期、日期范围、状态和任务类型筛选。
- 单项审核、批量全选和批量通过。
- 任务证明、实际用时、目标和审核重点展示。
- 审核建议、时间/质量/主动性评分。
- 打回原因、惩罚开关、惩罚级别、常用原因和自定义原因。
- 审核详情、已审核奖励/惩罚调整。
- 跨天任务提醒的完整列表与已读操作。

审批完成后统一刷新待审批数量、总览摘要、历史记录和报告数据；不能只更新当前卡片造成 Tab 徽标过期。

### 3.4 数据报告

数据报告保留现有 `/parent/stats` 与每周报告口径，不新造第二套统计公式：

- 提供孩子选择器；多孩子家庭默认“全部孩子”，选择单个孩子后只过滤该孩子可分解的数据。
- 保留连续打卡、今日/本周/本月/累计任务、类别分布、成长维度、体验质量、金币收入/消耗/净值、接近解锁成就和孩子成长快照。
- 保留每周报告、趋势和建议；建议只供家长参考，不自动改变奖励或任务。
- 数据报告首次进入时加载；加载失败只影响该 Tab，其他 Tab 仍可使用并提供重试按钮。

若现有 `/parent/stats` 缺少单孩子筛选能力，优先在已有接口增加可选 `childId`，并按 `familyId` 校验；不在前端重新计算业务统计。

### 3.5 全部工具

现有入口全部保留并按目的分组：

- **任务与日常：** 任务管理、学习闯关、早餐小厨房。
- **成长与支持：** 情绪/游戏票、规则/洞察、家庭探索。
- **奖励体系：** 心愿管理、特权设置、成就管理、惩罚设置。
- **家庭设置：** 家庭管理。

第一版不做“常用工具自定义排序”，避免增加偏好存储和额外设置负担。

## 4. 每日欢迎弹窗

### 4.1 展示规则

- 口径为“家长账号 + 北京时间业务日期”，所有设备合计每天最多自动展示一次。
- 新增 `users.parent_welcome_last_shown_date TEXT`，迁移前通过 `PRAGMA table_info(users)` 检查；只追加，不删除或重命名旧字段。
- 前端进入家长首页后调用 `POST /api/parent/daily-welcome/claim`。
- 后端用条件更新原子领取当天展示权；两个设备并发时最多一个返回 `shouldShow: true`。
- 接口失败时不阻塞家长首页，也不循环弹窗。
- 总览保留“查看今日提醒”入口，允许当天手动重开；手动重看不改变每日领取记录。

### 4.2 内容

有任务的家庭显示当天摘要：今日任务、待审批数量和一条周趋势。新家庭显示现有三步引导：添加任务、设置奖励、切换孩子账号。弹窗只做提示，不在弹窗中执行审批或修改奖励。

登录/注册页现有 `IntroModal` 是产品介绍，继续保留，不能与每日欢迎弹窗合并。

## 5. Phase 8B 任务管理

### 5.1 今日安排

- 默认显示所有孩子今天实际会看到的任务；多孩子家庭可切换孩子。
- 今日预览必须由后端复用 `getTasksForDate` 与 `shouldTaskAppearOnDate`，不能在前端复制周期判断。
- 每项显示任务名、类别、完成方式、奖励、当前状态和周期来源。
- 提供“编辑任务”与“新建任务”入口；今日预览本身不修改任务状态。
- 空状态明确区分“还没有任务”和“已有任务但今天不执行”。

新增 `GET /api/parent/tasks/today-preview`，只能读取当前家庭孩子数据。可选 `childId` 必须校验属于当前家庭；日期固定为当前北京时间，第一版不扩展任意日期模拟器。

### 5.2 全部任务

- 保留现有分类筛选、任务卡片、编辑和删除。
- 新建入口提供“从模板快速添加”和“自定义创建”两种方式。
- 模板批量选择、批量任务类型、自定义星期和奖励建议保持原逻辑。
- 任务保存后刷新全部任务与今日安排，让家长立即知道孩子端是否会出现。

### 5.3 家庭合作

保留家庭合作任务的独立列表、创建、编辑和删除能力。家庭合作继续使用现有接口和 `taskType = 'family'` 规则，不与个人任务混合，也不改变奖励结算。

### 5.4 任务编辑流程

任务底部抽屉按信息层级分为：

1. **基础信息：** 图标、名称、类别、预计时间。
2. **完成要求：** 完成方式、目标量、单位、家长审核重点。
3. **奖励：** 金币与成长经验，继续显示经济建议但不自动覆盖家长输入。
4. **显示与周期：** 每日、单次、自定义星期、并行任务。

首次展开只显示基础信息和当前必填的完成要求；奖励与周期以清晰分组展示，高级说明默认收起。编辑时所有旧值必须正确回填，不能因为字段折叠而保存成默认值。

## 6. 代码结构

家长首页只保留页面编排、核心数据加载和跨 Tab 刷新。计划拆分为：

- `ParentDashboard.tsx`：路由参数、核心加载、Tab 编排。
- `ParentDashboardTabs.tsx`：四 Tab 导航与徽标。
- `ParentOverviewTab.tsx`：当天摘要与空状态。
- `ParentApprovalTab.tsx`：审批列表、历史筛选和审批状态。
- `ParentReviewSheet.tsx`：单项审核流程。
- `ParentReportsTab.tsx`：周报与 `StatsPanel`。
- `ParentToolsTab.tsx`：工具分组与路由。
- `ParentDailyWelcomeModal.tsx`：每日欢迎展示。

任务管理计划拆分为：

- `ParentTasks.tsx`：三 Tab 编排和刷新。
- `ParentTodayTasksTab.tsx`：后端今日预览。
- `ParentTaskListTab.tsx`：全部任务和分类筛选。
- `ParentFamilyMissionsTab.tsx`：家庭合作。
- `TaskEditorSheet.tsx`：新建/编辑共用表单。
- `TaskTemplatePicker.tsx`：模板批量选择。

只有真正复用的新建/编辑字段才抽成共用组件，不建立泛化表单框架。类型定义放在对应功能目录，逐步消除本次触及区域的 `any`，不重构无关页面或 7200 行后端文件的其他区域。

当前家长首页的“惩罚分析仪表盘”没有入口，状态永远为 `null`，属于不可达代码。实施时先通过全仓搜索和测试再次确认；确认不可达后删除该弹窗及专属死状态。正常的惩罚设置页面、审核惩罚、惩罚记录和奖励调整全部保留。

## 7. 数据流与错误处理

- `/parent/dashboard`、`/parent/inbox`、跨天提醒与周报继续使用现有接口。
- 核心加载部分失败时保留可用数据；任何单个接口失败都不能导致整个家长首页白屏。
- 审批写操作成功后调用统一刷新函数；失败保留当前输入并显示后端错误。
- 报告和今日预览按 Tab 延迟加载，并提供独立加载、空状态和重试状态。
- 欢迎领取失败不影响页面，手动“查看今日提醒”仍可使用已经加载的总览数据。
- 所有角色与家庭隔离继续由后端 JWT、`role` 和 `familyId` 校验，前端筛选不作为权限边界。

## 8. 兼容与验证清单

### 8.1 后端

1. 旧数据库启动后幂等增加欢迎日期字段，重复启动不报错。
2. 同一家长同一天两个并发欢迎领取请求最多一个 `shouldShow: true`。
3. 北京时间跨日后重新允许展示；不同家长互不影响。
4. 孩子角色不能调用欢迎领取和今日预览。
5. 今日预览与孩子 `/child/dashboard` 返回的当天任务 ID 集合一致。
6. 单次、每日、自定义星期和旧兼容周期均使用同一日期规则。
7. `childId` 越权返回 403/404，不泄露其他家庭数据。

### 8.2 前端 375px smoke

1. 四 Tab 可点击，默认总览，审批徽标数量正确，URL 参数可恢复。
2. 每日欢迎自动弹出一次，关闭后不再自动弹；总览可手动重看。
3. 总览、审批、报告或工具任一接口失败时其他 Tab 不白屏。
4. 待审批、历史筛选、批量通过、单项审核、打回、奖励调整与惩罚流程可完成。
5. 报告能切换孩子并保留现有概览、金币和成就数据。
6. 11 个工具入口全部可进入原有路由并正常返回。
7. 今日安排与孩子端任务集合一致；新增、编辑后立即刷新。
8. 模板批量创建、单次/每日/自定义星期、完成方式、审核重点、奖励与并行设置全部保留。
9. 家庭合作任务可创建、编辑和删除。
10. 全量现有 Playwright smoke、前后端 build 全部通过，无跳过。

- 不重写统计口径，不让前端自行推导后端业务统计。
- 不做工具自定义排序、任意日期任务模拟或家长端桌面专属布局。
- 不借本次机会重构与家长首页、任务管理无关的后端模块。
