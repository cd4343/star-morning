# Star Coin v1.0.6 发布说明

日期：2026-05-14

## 本次新增

- 新增“学习闯关”MVP。
- 家长端新增“学习闯关”管理入口，可用模板创建数学作业、背诵、阅读等学习关卡。
- 家长可把学习任务拆成多个 3-10 分钟小关卡，并设置金币、经验和提示语。
- 孩子端新增“学习星图”，可以开始关卡、进行小关卡倒计时、点击“我卡住了”、提交学习证明。
- 家长端可以审核孩子提交的学习关卡，通过后发放金币和经验。
- 新增手机号/短信验证码/一键登录规划文档和测试清单。
- 数据库为后续手机号和一键登录预留字段。

## 上线影响

- 需要更新前端和后端程序。
- 不需要覆盖服务器数据库。
- 后端启动时会新增学习闯关相关表：`learning_quests`、`learning_steps`、`learning_sessions`。
- 后端启动时会为 `users` 追加手机号/登录 provider 预留字段。
- 现有任务、金币、背包、成就、宝箱、家庭数据不会被替换。

## 建议回归

- 家长端：进入“学习闯关”、用模板创建关卡、查看关卡列表、审核学习提交。
- 孩子端：进入“学习”、开始关卡、完成小关卡、点击“我卡住了”、提交证明。
- 登录：原手机号密码登录、注册、选择家庭成员、孩子切换家长模式。
