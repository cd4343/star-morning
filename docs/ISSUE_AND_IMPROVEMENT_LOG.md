# Star Coin 问题与优化记录

本文件用于记录每次代码检查、修改建议、已知问题、验证结果和上线影响。后续每次提出问题或改动建议，都应追加到这里，方便按版本回溯。

## 记录规则

- 每条问题保留编号、发现日期、影响范围、严重级别、当前状态和建议版本。
- 状态：`待修复`、`修复中`、`已修复待验证`、`已验证`、`暂缓`。
- 上线前必须确认：数据库备份、兼容迁移、前后端版本号、回滚方式。

- 本次只新增表和接口，不需要用本地数据库替换服务器数据库。

- 服务器生产环境如果未配置 `SMS_PROVIDER`，验证码接口会返回“短信服务尚未配置”，不会假装发送成功。
- 如果要开启真实短信，需要先选择服务商并配置密钥、签名、模板 ID，再把 `SMS_PROVIDER` 接到对应实现。
