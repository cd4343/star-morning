# Star Coin v1.0.5 发布说明

日期：2026-05-13

## 本次修复

- 修正孩子端弹窗仍未居中的问题：弹窗内部坐标改为相对手机内容区计算。
- 宝箱、任务详情、行为警示、倒计时弹窗统一渲染在孩子端手机框内，避免跑到浏览器右侧或底部。
- 进行中任务悬浮窗默认显示在内容区顶部，不覆盖最上方孩子信息栏，并可继续拖动。
- 孩子端增加“宝箱说明”，展示宝箱触发规则、保底和可能奖品。
- 全家任务和普通任务完成后都优先显示宝箱奖励。
- 成就达成后自动发放奖励，支持立即到账或放入背包作为成就礼包打开。
- 家长端任务、商品、特权设置增加规则助手，用于说明金币、经验、特权点的设置依据。
- 任务列表增加“并行”标签，便于在上级页面识别。
- 宝箱奖品稀有度旧数据增加兜底，降低宝箱设置页白屏风险。

## 上线影响

- 需要更新前端和后端程序。
- 不需要覆盖服务器数据库。
- 后端启动时只会追加缺失字段：`achievement_defs.rewardDelivery`、`user_inventory.rewardCoins`、`user_inventory.rewardXp`、`user_inventory.rewardPrivilegePoints`。
- 已有成就、背包、金币、经验、任务记录不会被删除或替换。
- 已经解锁的历史成就不会自动补发奖励，避免线上数据突然变化。

## 建议回归

- 孩子端：打开正在进行任务、完成普通任务、完成全家任务、查看宝箱说明、打开成就礼包。
- 家长端：宝箱设置页、任务并行标签、任务奖励助手、商品金币助手、特权点助手、成就奖励领取方式。
