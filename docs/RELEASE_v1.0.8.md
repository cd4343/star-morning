# Star Coin v1.0.8 发布说明

日期：2026-05-14

## 本次新增

- 新增“早餐/早晨”家长端入口。
- 新增“早晨”孩子端入口。
- 家长可以维护早餐菜单：名称、图标、分类、说明、金币消耗。
- 家长可以维护早晨流程：坐起来、喝水、洗漱、穿衣、能量操等小步骤，并设置金币、经验、能量奖励。
- 孩子可以完成早晨小步骤获得即时金币/经验/能量反馈。
- 孩子可以选择今日早餐：基础早餐免费，升级早餐消耗金币。
- 家长可以查看今日每个孩子选择的早餐和早晨步骤完成情况。

## 上线影响

- 需要更新前端和后端程序。
- 不需要覆盖服务器数据库。
- 后端启动时会新增四张表：`breakfast_items`、`breakfast_orders`、`morning_routine_steps`、`morning_routine_logs`。
- 后端首次访问早餐/早晨接口时会为每个家庭创建默认早餐和默认早晨步骤。
- 现有任务、金币、经验、家庭、心愿、成就、宝箱数据不会被替换。
- 孩子完成早晨步骤会增加少量金币和经验；选择付费早餐会扣减金币。

## 建议回归

- 家长端：进入“早餐/早晨”、新增/编辑/停用早餐项、新增/编辑/停用早晨步骤。
- 孩子端：进入“早晨”、完成步骤、确认金币和经验变化、选择免费早餐、金币足够时选择升级早餐。
- 数据：确认同一天孩子只能选择一次未取消的早餐，早晨步骤同一天不能重复领取奖励。
- 上线：服务器升级时只部署程序和构建产物，不使用本地 SQLite 覆盖服务器数据库。
